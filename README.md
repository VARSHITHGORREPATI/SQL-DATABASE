# SQL Database Practice 🗄️

A learning repository for SQL queries, database design, joins, aggregations, and database exercises.

## 📚 Suggested Areas

- Database and table design
- CRUD queries
- Joins and aggregations
- Subqueries and CTEs
- Views, indexes, and constraints
- Stored procedures
- Practice problems

## 🎯 Goal

Build a collection of clear, runnable SQL examples using synthetic data and document the target database engine for each example.
